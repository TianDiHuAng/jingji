银行挤兑

银行挤兑：存款人因担心银行倒闭而集中提款，在部分准备金制度下可自我实现地使银行破产。

银行理论制度全球L3 · 核心

概述

银行挤兑指大量存款人同时提取存款的行为。由于银行实行部分准备金制度——把存款投向长期不流动的贷款与证券，只保留少量现金——任何"先到先得"的预期都可能使所有存款人的理性反应变成集体灾难：人人都想先取款，结果银行被迫贱卖资产，最终真的倒闭。戴蒙德与迪布维格(Diamond & Dybvig, 1983) 用多重均衡模型刻画了这一逻辑："都不挤兑"与"都挤兑"都是均衡，挤兑可由与基本面无关的事件（太阳黑子）触发。政策含义是：存款保险、最后贷款人与流动性监管能通过消除挤兑动机来"挑选好均衡"。1983年该模型成为银行理论的基础，2022年其作者获诺贝尔经济学奖。具体模型细节与批评待核实。

时间线

  • 1933年：美国设立FDIC，以存款保险抑制挤兑（见 deposit-insurance） [Deposit insurance]
  • 1983年：Diamond-Dybvig 提出银行挤兑的多重均衡模型 [Bank run]

触发与传导机制

  1. 负面信息/信心动摇 → 存款人集中提款 [Bank run]
  2. 挤兑自我实现 → 健康银行亦受牵连 [Systemic risk]
  3. 信贷收缩 → 实体经济融资中断 [Credit crunch]

各方解释

  • 挤兑均衡视角：挤兑可视为协调博弈的坏均衡 （依据：类型学框架；待核实 [Bank run]）
  • 系统性风险视角：强调机构关联与传染 （依据：类型学框架；待核实 [Systemic risk]）

与其他案例的相似与不同

与银行恐慌(bank panic) 的区别在范围：bank run 指单一机构遭遇挤兑（可由传闻、坏消息或对手方风险触发）；bank panic 指挤兑在多机构间蔓延，形成系统性事件。两者的微观机制相同（部分准备金下的协调失败，见 diamond-dybvig），但政策含义不同：单一挤兑可用流动性支持与存款保险化解，系统性恐慌则需要最后贷款人提供市场整体流动性。北岩银行2007年是最纯粹的单一机构批发融资挤兑；1907年恐慌则是典型的系统性事件。
