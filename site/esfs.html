欧洲金融监管体系(ESFS)

欧盟金融监管框架，自2011年起运作，由欧洲监管局等构成。

制度理论制度全球L2 · 重要

概述

欧洲金融监管体系(European System of Financial Supervision, ESFS) 是2008 年危机后欧盟建立的金融监管架构，旨在把宏观审慎与微观审慎的职责分开并加强跨境协调。它的组成部分（这一分工是设计的关键）：欧洲系统性风险委员会(ESRB)——负责宏观审慎，识别全系统的风险并发出警告与建议；三家欧洲监管局(ESA)——分别负责银行(EBA)、证券(ESMA)与保险(ΕΙΟPA)的微观审慎规则协调；以及各国监管机构——保留日常监管权。为什么采用"网络"而非"单一机构"：监管权在国家层面，而风险跨越国界——直接集中权力在政治上不可行，因此选择"协调 + 标准统一"的折中。它的固有弱点（在后续危机中被反复暴露）：①缺乏直接处置权——ESA 主要是规则制定者，不能直接干预一家具体银行；②财政责任仍在各国——救助用本国纳税人的钱，因此各国在跨境处置上难以达成一致；③宏观审慎工具的执行依赖各国——ESRB 的建议不具强制力。后续发展：银行业联盟（单一监管机制 SSM 与单一处置机制 SRM）把欧元区大银行的监管权集中到 ECB，这是对上述弱点的部分回应。

时间线

  • 2011年起：ESFS 开始运作（据 Wikipedia ESFS） [European System of Financial Supervision]

触发与传导机制

  1. 危机暴露成员国监管分割 → 需欧盟层面协调 [2008 financial crisis]
  2. 建立 ESFS 与三家欧洲监管局 → 统一规则与协调 [European System of Financial Supervision]
  3. 与 ESRB 宏观审慎职能配合 [European Systemic Risk Board]
