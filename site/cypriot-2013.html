2012–2013塞浦路斯金融危机

2012–2013塞浦路斯金融危机：发生于21世纪、地区为欧洲的银行类案例（轮次4新条目，骨架）。

银行21世纪欧洲L2 · 重要

概述

2012–2013塞浦路斯金融危机 是经权威大纲（Wikipedia List of banking crises）对照发现的遗漏案例，维基页面已核对存在。完整内容待逐条核实来源后补充。

时间线

  • 2011年：不良贷款率升至6.1%，银行体系压力加大（据 Wikipedia Cypriot financial crisis） [2012–2013 Cypriot financial crisis]
  • 2013年3月18日：因担忧银行挤兑，塞浦路斯关闭所有银行（同上） [2012–2013 Cypriot financial crisis]

触发与传导机制

  1. 塞浦路斯银行对过度杠杆的本地地产公司及希腊主权债务的敞口 → 评级被下调至垃圾级 [2012–2013 Cypriot financial crisis]
  2. 无法从国际市场融资、政府不愿重组问题银行 → 危机深化 [2012–2013 Cypriot financial crisis]
  3. 2013年3月欧元集团等提供100亿欧元救助，代价是关闭第二大银行、对未保险存款征一次税 [2012–2013 Cypriot financial crisis]

各方解释

  • 主权-银行关联视角：银行大量持有本国与希腊主权债，主权风险与银行风险相互放大 （依据：据维基原文归纳；具体表述待核实 [2012–2013 Cypriot financial crisis]）
  • 银行挤兑/救助视角：救助附带存款减记(bail-in)引发对存款安全的担忧 （依据：据维基原文归纳；具体表述待核实 [2012–2013 Cypriot financial crisis]）
