2012–2013塞浦路斯金融危机

塞浦路斯危机(2012–2013)：银行体系崩溃后以"存款减记"(bail-in)换取救助，超10万欧元存款被征47.5%。

银行21世纪欧洲L2 · 重要

概述

塞浦路斯金融危机（2012—2013年）是欧元区危机中唯一以存款减记(bail-in) 为核心处置方式的案例。塞浦路斯银行体系因大量持有希腊国债（希腊PSI减记损失）与本国房地产贷款而资本枯竭，规模相对GDP过大使其无法像其他国家一样以主权资金救助。2013年3月的救助协议规定：10万欧元以下的保险存款不受影响，但超过10万欧元的存款被征收 47.5%。危机造成商业地产价值下跌约 30%，不良贷款在2011年已升至 6.1%；经济在2009年已萎缩 1.67%，旅游与航运下滑推高失业。该案例成为"bail-in 与 bail-out 之争""存款保险边界"的关键参照

时间线

  • 2011年：不良贷款升至6.1%，银行压力上升 [2012–2013 Cypriot financial crisis]
  • 2013年3月：救助协议：超10万欧元存款被征47.5% [2012–2013 Cypriot financial crisis]
  • 2013年：商业地产价值下跌约30% [2012–2013 Cypriot financial crisis]

触发与传导机制

  1. 塞浦路斯银行对过度杠杆的本地地产公司及希腊主权债务的敞口 → 评级被下调至垃圾级 [2012–2013 Cypriot financial crisis]
  2. 无法从国际市场融资、政府不愿重组问题银行 → 危机深化 [2012–2013 Cypriot financial crisis]
  3. 2013年3月欧元集团等提供100亿欧元救助，代价是关闭第二大银行、对未保险存款征一次税 [2012–2013 Cypriot financial crisis]

与其他案例的相似与不同

塞浦路斯是欧元区危机中唯一以存款减记(bail-in)为核心的案例（见 bail-in），与希腊、爱尔兰、葡萄牙的外部救助形成对照：那些国家赌的是主权偿付能力，塞浦路斯赌的是银行体系规模超过国家救助能力（与冰岛2008年、见 icelandic-crisis-2008 同型）。其独特性在于把损失直接分配到超过存款保险限额的存款人，这在欧元区是首次，也使"存款是否安全"成为此后银行危机中反复出现的信任问题。与2013年之后的处置框架（BRRD）相比，塞浦路斯是"先行个案"而非有规则约束的操作。
