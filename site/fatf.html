金融行动特别工作组(FATF)

1989年由G7倡议成立的政府间组织，负责制定反洗钱与反恐融资政策。

制度理论制度全球L2 · 重要

概述

金融行动特别工作组(FATF) 是制定反洗钱与反恐融资(AML/CFT)国际标准的政府间机构，成立于 1989 年。它的核心产出是"四十项建议"——一套要求各国建立的法律与监管框架：客户尽职调查(KYC)、可疑交易报告、受益所有权透明、以及对不合作国家实施制裁。它的执行机制很有特点：互评估(mutual evaluation)——成员国相互审查，结果公开并分级；"灰名单"与"黑名单"——被列入会显著提高该国的跨境交易成本，因此声誉压力是其最主要的执行手段（它没有强制执法权）。与金融危机的关系（间接但重要）：①反洗钱要求提高了金融体系的透明度，但也提高了开户与跨境支付的门槛，对金融包容（见 financial-inclusion）构成张力；②"去风险化"(de-risking)——银行为避免合规风险而终止与某些客户或地区的关系，可能把资金推向监管更弱的渠道；③它揭示了一个普遍问题：合规成本是固定的，而机构规模不同——大机构能承担，小机构与低收入客户被排除；④加密货币与稳定币（见 cryptocurrency、stablecoin）的监管框架近年成为 FATF 的重点，其"旅行规则"要求转账时传递客户信息。本库的处理：记录其职能与张力，不评价具体国家的执行情况。

触发与传导机制

  1. 洗钱与金融犯罪跨境化 → 需国际标准 [Financial Action Task Force]
  2. FATF 建议 + 互评估 → 推动各国立法 [Financial Action Task Force]
  3. "不合作辖区"名单 → 形成实质约束力 [Financial Action Task Force]
