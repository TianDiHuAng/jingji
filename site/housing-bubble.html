房地产泡沫

在地方或全球房地产市场周期性出现的资产泡沫，通常跟随土地价格与信贷扩张。

泡沫理论制度全球L2 · 重要

概述

房地产泡沫（real-estate bubble 或 property bubble）是在地方或全球房地产市场周期性出现的一类经济泡沫，通常伴随着土地价格与信贷的扩张。其共同机制与一般资产泡沫一致：信贷可得性上升 → 房价上涨 → 抵押品价值上升 → 进一步放宽信贷 → 房价再涨；而房地产的特殊性在于杠杆高、供给调整慢、且与银行体系深度绑定，因此破裂时的破坏力远超股票泡沫——2007—08年全球危机即由美国房价下跌触发。识别指标包括房价收入比、房价租金比、信贷/GDP 缺口与建筑投资占比，但均存在局限。经典案例：日本1990（见 japan-asset-bubble-1990）、西班牙2008、爱尔兰2008、新西兰1990s以来（见 nz-property-bubble）、中国2020年以来（见 china-realestate-2020）

触发与传导机制

  1. 低利率与信贷扩张 → 住房需求与房价上升 [Real-estate bubble]
  2. 抵押品升值 → 进一步放宽信贷（顺周期） [Financial accelerator]
  3. 利率上行或预期逆转 → 价格下跌，通过银行体系放大冲击 [Subprime mortgage crisis]

各方解释

  • 信贷视角：泡沫由信贷扩张驱动，货币条件变化是关键 （依据：据来源/标准口径归纳；具体表述待核实 [Real-estate bubble]）
  • 供给视角：土地与规划约束使供给弹性低，价格对需求冲击更敏感 （依据：据来源/标准口径归纳；具体表述待核实 [New Zealand property bubble]）

与其他案例的相似与不同

与股票泡沫的区别在"杠杆与传导"：房地产泡沫通常伴随高杠杆（按揭）与银行体系深度绑定，因此破裂时的破坏力远超股市泡沫；且房地产的供给调整慢（建设周期长），价格对需求冲击更敏感。这一区别解释了为何2007年美国房价下跌能引发全球金融危机，而2000年纳斯达克跌78%却只造成温和衰退。
