交易成本

达成与执行交易所需的成本（搜寻、议价、监督、履约）；是解释制度为何存在的核心概念。

理论理论制度全球L2 · 重要

概述

（据 Wikipedia「Transaction cost」摘要归纳）In economics, a transaction cost is a cost incurred when making an economic trade when participating in a market. 具体定义边界与争议待核实。

时间线

  • ：制度经济学家 John R. Commons 提出以"交易"而非商品或个人作为经济理论的基础（据 Wikipedia Transaction cost） []
  • ：威廉姆森在《治理机制》中系统列出交易成本经济学与新古典微观经济学的分歧（据 Wikipedia Transaction cost） []

各方解释

  • 交易成本经济学（威廉姆森）：拒绝"工具理性"假设及其对行为的预测含义，认为有限理性与机会主义使治理结构（市场/企业/混合）成为关键变量（据 Wikipedia Transaction cost） （依据： []）
  • 新古典微观经济学：以工具理性与完全信息为基准，把交易本身视为无摩擦，因此不把治理结构作为分析对象（据 Wikipedia Transaction cost） （依据： []）

与其他案例的相似与不同

与生产成本的区别在"交易而非制造"：生产成本是制造商品的投入（劳动、原料、机器）；交易成本是达成与执行交易的成本（搜寻、议价、监督、履约）。这一区分是制度经济学的核心：企业之所以存在，是因为在某些情形下用内部指令替代市场交易更省成本（科斯）；而金融中介（银行、评级、交易所）本质上也是降低交易成本的制度。危机中交易成本骤升（信息不对称加剧、信任崩塌），是市场冻结的直接原因。
