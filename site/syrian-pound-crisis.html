叙利亚镑贬值与汇率分裂(2011–)

叙利亚镑自2011年战争爆发后大幅贬值，官方与市场汇率分化，2017年已达515镑/美元。

货币21世纪中东L2 · 补充

概述

叙利亚镑(SYP) 是叙利亚的官方货币，由叙利亚中央银行发行，名义上分为100皮阿斯特，目前仅发行纸币。历史上其汇率长期稳定：1947年之前与（某货币挂钩）；对美元汇率 LS 2.19148 = US$1 的平价一直维持到 1961年。2000年代初常见汇率约为 LS 50 = US$1；2005年12月5日商业叙利亚银行报价为 LS 48.4 = US$1。2011年3月内战爆发前为 LS 47 = US$1，到 2017年7月已贬至 LS 515 = US$1。战时经济下官方汇率与黑市汇率严重分化，外汇短缺、制裁与产出崩溃使货币持续承压。2025年前后叙利亚政权更迭后，货币安排与汇率统一问题成为重建议题之一（细节待核实）。

时间线

  • 至1961年：对美元平价 LS 2.19148 = US$1 维持至此 [Syrian pound]
  • 2005年12月5日：商业叙利亚银行卖出价 LS 48.4 = US$1 [Syrian pound]
  • 2011年3月：内战爆发前 LS 47 = US$1 [Syrian pound]
  • 2017年7月：贬至 LS 515 = US$1 [Syrian pound]

触发与传导机制

  1. 内战爆发 → 产出崩溃、外汇收入锐减与制裁 [Syrian pound]
  2. 外汇短缺 + 财政货币化 → 里亚尔（镑）持续贬值 [Syrian pound]
  3. 官方与黑市汇率分化 → 多重汇率、支付与物价区域化 [Yemeni rial]

各方解释

  • 战争经济视角：汇率贬值是产出崩溃与外汇短缺的直接反映 （依据：据汇率数据归纳 [Syrian pound]）
  • 多重汇率视角：官方与市场汇率分化本身会扭曲资源配置并滋生寻租 （依据：据多重汇率通行分析归纳 [Yemeni rial]）

政策应对及评价分歧

  • 政策当局：战后货币改革：2024 年底阿萨德政权倒台后，领导过渡政府的总统 Ahmed al-Sharaa 表示，拟在货币稳定后以新货币取代叙利亚镑。2025年8月宣布将对货币进行重估——去掉两个零并于 12 月发行新钞；10 月当局再次确认该计划但把日期推迟至 2026 年。2025年12月29日，叙利亚央行与总统共同公布了新版叙利亚镑的面额。 （据 Wikipedia 相关条目 Post-Assad reforms 章节；政策主体：叙利亚过渡政府/央行；动作：货币重估（去两个零）、发行新钞；效果评价待核实）
