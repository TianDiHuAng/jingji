洗钱

非法所得通过复杂交易掩饰来源、使其看似合法的过程。

其他理论制度全球L2 · 重要

概述

洗钱(money laundering) 是**非法掩饰非法所得来源**、并把资金转换为看似合法形式的过程（俗称"脏钱"）。典型环节包括：处置(placement，把现金注入金融体系)、分层(layering，通过多层交易模糊来源) 与整合(integration，以合法形式取回)。在金融危机语境中，洗钱的意义有三：①**银行体系的脆弱点**——反洗钱失效导致的罚款与声誉损失可危及机构生存；②**与资本管制/多重汇率的互动**——管制越严，地下跨境渠道越活跃（见 black-market）；③**危机后的监管强化**——FATF 标准与"去风险化"(de-risking) 影响新兴市场的代理行关系。相关国际标准由 FATF（见 fatf 条目）制定。具体机制与规模估计待核实。

触发与传导机制

  1. 非法所得需掩饰来源 → 通过金融体系分层转移 [Money laundering]
  2. 管制与多重汇率 → 地下跨境渠道扩张 [Black market]
  3. 反洗钱标准强化 → 代理行关系收缩（去风险化）影响新兴市场 [Financial Action Task Force]

各方解释

  • 执法视角：强化反洗钱可切断犯罪资金链并提升金融体系完整性 （依据：据来源/标准口径归纳；具体表述待核实 [Money laundering]）
  • 去风险化视角：过度合规使新兴市场失去代理行服务，反而推高非正规渠道 （依据：据来源/标准口径归纳；具体表述待核实 [Financial Action Task Force]）

与其他案例的相似与不同

与**资本外逃**的区别在"资金来源与合法性"：洗钱是掩饰**非法所得**的来源（贩毒、腐败、诈骗），使其看似合法；资本外逃是转移**合法或非法**资产以规避本国风险。两者在危机中的联系是：资本管制越严，洗钱与地下汇兑渠道越活跃（见 black-market）；而反洗钱标准（FATF）的强化又会通过"去风险化"收缩代理行关系，影响新兴市场的正常跨境支付。
