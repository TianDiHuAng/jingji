信用违约互换(CDS)

一种转移信用风险的金融衍生合约：买方支付保费，在标的违约时获赔。

制度理论制度全球L2 · 重要

概述

信用违约互换(CDS) 是一种信用风险转移工具：保护买方定期向卖方支付费用，若标的债务发生违约（或其他约定信用事件），由卖方赔付。它像保险但不是保险：买方不必实际持有标的债券——因此既可用于对冲（持有债券者转移风险），也可用于投机（不持有债券而押注违约）。为什么引起监管关注：①对手方风险：保护买方以为已转移风险，但若保护卖方本身倒下（如 2008 年的 AIG），风险又回到原处；②集中度：少数大型机构互为对手方，网络中任何一家倒下都会牵动全体；③信息功能：CDS 利差成为市场对信用风险的实时定价，在危机中其飙升常先于评级下调。与本库案例：2008 年 AIG 因承保大量 CDS 而在抵押品追缴下濒临破产，救助的核心争议之一就是"CDS 把风险转到了谁身上"。制度回应：危机后推动 中央对手方清算（见 central-counterparty）与交易报告，以降低网络不透明。

触发与传导机制

  1. 债权人购买CDS → 将违约风险转移给卖方 [Credit default swap]
  2. 支付保费获得违约保护 [Credit default swap]
  3. 违约时卖方赔付；集中持仓放大对手方风险 [Systemic risk]

与其他案例的相似与不同

与保险的区别在"可保利益"：保险要求投保人对标的拥有可保利益（不能给邻居的房子投保）；CDS 允许"裸买"——买入方不必持有标的债券，即可对他人违约下注。这一差别带来两个后果：①CDS 名义规模可远超标的债券存量（AIG 的 CDS 敞口即如此）；②它把信用风险从"分散"变为"集中"——风险最终聚到少数卖方（AIG、单一险种保险公司）。2008年AIG的救助核心即在于此。
