信用违约互换(CDS)

一种转移信用风险的金融衍生合约：买方支付保费，在标的违约时获赔。

制度理论制度全球L2 · 重要

概述

信用违约互换(CDS)是信用风险转移工具：保护买方定期支付费用，若标的债务违约则由卖方赔付。它可用于对冲或投机，其集中与对手方风险在2008年危机中受关注。具体条款与规模待核实。

触发与传导机制

  1. 债权人购买CDS → 将违约风险转移给卖方 [Credit default swap]
  2. 支付保费获得违约保护 [Credit default swap]
  3. 违约时卖方赔付；集中持仓放大对手方风险 [Systemic risk]

  • 风险管理视角：CDS便于对冲与价格发现 （依据：据维基原题/标准经济学口径归纳；具体表述待核实 [Credit default swap]）
  • 系统性风险视角：不透明与高杠杆可能放大传染 （依据：据维基原题/标准经济学口径归纳；具体表述待核实 [Systemic risk]）
